# 🎂 Mayur The Cake Expert

> Artisanal Cakes, Cookies & Handcrafted Celebration Treats — Made with Love by Mayur The Cake Expert.

A modern, responsive, high-converting bakery landing page and online ordering web application built for **Mayur The Cake Expert** (`@mayurthecakeexpert`).

---

## ✨ Features

- **🍰 Elegant Hero Section:** High-resolution bakery backdrop with Classic Tiramisu, warm cream aesthetics, and intuitive call-to-action buttons.
- **🏷️ Interactive Category Pills:** Dynamic filtering across **Cakes**, **Donuts**, **Cookies**, **Cupcakes**, **Brownies**, and **Gift Boxes**.
- **🍪 Our Special Treats Carousel:** Featuring bestseller items like *Cookie Tins*, *Classic Tiramisu*, and *Tiramisu Truffles* with wishlist toggles, pricing, and fast cart access.
- **🛒 Interactive Shopping Cart Drawer:** Full cart management with real-time totals, quantity steppers, dietary preferences (100% Eggless 🌱), and customizable cake inscriptions.
- **💬 Direct WhatsApp Ordering:** One-click automated order generation formatted for WhatsApp (`+91 82375 76793`).
- **🎂 Custom Celebration Cake Designer:** Detailed custom inquiry modal for birthdays, anniversaries, weddings, and festivals.
- **📱 100% Mobile & Desktop Responsive:** Tailored layout for seamless browsing on phones, tablets, and wide screens.

---

## 🚀 Quick Start

1. Clone or download the repository:
   ```bash
   git clone https://github.com/TheMarsStudio/mayurthecakeexpert.git
   cd mayurthecakeexpert
   ```

2. Open `index.html` in your browser:
   - Or start a local server:
     ```bash
     python -m http.server 8080
     ```
   - Visit `http://localhost:8080`

## 🛠️ Tech Stack

- **HTML5 & CSS3** (Vanilla, optimized for high performance)
- **Tailwind CSS** (Utility framework)
- **JavaScript (ES6+)** (Cart state, wishlist, carousel slider, modal management)
- **Google Fonts** (`Cormorant Garamond`, `Playfair Display`, `Outfit`, `Caveat`)
